# **App Name**: SB Public Portal

## Core Features:

- Secure Authentication: Secure access using Google authentication.
- Announcements Display: Display school announcements in a clear, chronological format.
- Events Calendar: Show upcoming school events in a calendar view.
- About Us Section: Present school details, history, and mission.
- Curriculum Overview: Outline the school's curriculum by grade level.
- Contact Information: A dedicated page with all ways of contacting the school's administration.
- Emergency Broadcasts: Tool which analyzes latest news to flag potential impact on school operations.

## Style Guidelines:

- Primary color: Professional blue (#3498DB), conveying trust and stability.
- Background color: Light blue (#EBF5FB), creating a calm and professional backdrop.
- Accent color: Darker blue (#2980B9), used sparingly to highlight important elements and calls to action.
- Body and headline font: 'PT Sans' (sans-serif), known for readability and modern appearance.
- Use flat, modern icons in blue tones to represent different sections.
- Clean, responsive layout optimized for desktop and mobile viewing.
- Subtle transitions and animations for a smooth user experience.
